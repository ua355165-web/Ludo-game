# Ludo Royale

A real Android Studio starter project built with Kotlin, Jetpack Compose, Material 3, MVVM, and Navigation Compose.

## Build
Open this folder in Android Studio, allow Gradle sync, then run `./gradlew assembleDebug` or use Build > Generate Signed Bundle / APK.

This foundation intentionally contains no Firebase, ads, online multiplayer, or advanced Ludo gameplay.
